## 摘要
预测视频模型已成为一种有前景的世界模型，通过从大规模视频中学习潜在视觉动态。然而，这些模型在遮挡下的物理事件中仍面临挑战，后续预测可能依赖于当前视图中不再可用的对象证据。解决这一挑战要求历史证据不仅被保留，而且在其与后续预测相关时保持可访问。现有方法主要扩大时间上下文、缓存通用视频特征或施加显式对象中心状态，从而提高了保留历史的容量或结构。然而，它们并未直接解决如何在不干扰预训练预测器原生潜在工作空间的情况下，选择性地检索并整合相关历史证据。为此，我们引入了HERA（历史证据路由适配器），一种将保留的历史证据路由到冻结潜在预测器中的框架，并实例化为寄存器路由补丁记忆（RRPM），一种轻量级适配器，包含结构化记忆库、记忆寄存器和工作空间寄存器。在IntPhys2 Main划分上，带有RRPM的HERA将V-JEPA 2-G的成对平均惊喜准确率从52.57%提升至54.35%。亚组分析显示，在固定相机连续性上从46.15%提升至57.69%，在固定相机不变性上从46.15%提升至63.46%的显著改进。这些结果支持历史证据路由作为潜在世界模型中物理预测的一种实用适应策略。

## Abstract
Predictive video models have emerged as promising world models by learning latent visual dynamics from large-scale video. Yet these models remain challenged by physical events under occlusion, where later predictions may depend on object evidence that is no longer available in the current view. Addressing this challenge requires historical evidence not only to be preserved but also to remain accessible when it becomes relevant to a subsequent prediction. Existing approaches mainly enlarge the temporal context, cache generic video features, or impose explicit object-centric states, thereby improving the capacity or structure of retained history. However, they do not directly address how relevant historical evidence can be selectively retrieved and integrated into a pretrained predictor without interfering with its native latent workspace. Accordingly, we introduce HERA (Historical Evidence Routing Adapter), a framework for routing retained historical evidence into a frozen latent predictor, and instantiate it with Register-Routed Patch Memory (RRPM), a lightweight adapter comprising a Structured Memory Bank, Memory Registers, and Workspace Registers. On the IntPhys2 Main split, HERA with RRPM improves the pairwise AvgSurprise accuracy of V-JEPA 2-G from 52.57% to 54.35%. Subgroup analysis shows particularly strong improvements on fixed-camera continuity, from 46.15% to 57.69%, and fixed-camera immutability, from 46.15% to 63.46%. These results support historical evidence routing as a practical adaptation strategy for physical prediction in latent world models.

## 2. 方法论

### 2.1 核心思想

- 提出 **HERA（Historical Evidence Routing Adapter）** 框架：在**冻结的 V-JEPA 2 预测器**上增加轻量适配，将保留的历史证据选择性检索并注入预测过程，且不改变预训练模型的原生预测路径。
- 实例化为 **RRPM（Register-Routed Patch Memory）**，由三个模块组成：
  - **结构化记忆库（Structured Memory Bank）**：负责历史证据的保存与组织；
  - **记忆寄存器（Memory Registers）**：通过门控交叉注意力从记忆库选择性检索历史证据；
  - **工作空间寄存器（Workspace Registers）**：通过预训练预测器原生的自注意力路径，将检索到的证据整合进后续预测。

### 2.2 关键技术细节

- **诊断框架（物理违背探测）**：使用 IntPhys2 的匹配可能/不可能视频对。对每个视频计算滑动窗口的未来潜在预测误差（AvgSurprise），不可能视频应产生更大的惊奇度。成对正确率定义为 `AvgSurprise(不可能) > AvgSurprise(可能)`。
- **问题形式化**：给定上下文编码器 `Eϕ`、目标编码器 `E¯ϕ` 和预测器 `Gψ`，预测器接收上下文 token 与未来掩码 token，输出未来目标潜在表示。记忆增强后的预测形式为：
  `Ẑ = G_mem(Xp, Y_mask, M, R_w, R_mem)`
  其中 `M` 为结构化记忆库，`R_w` 为工作空间寄存器，`R_mem` 为记忆寄存器。
- **结构化记忆库**：将上下文按时间角色划分为四组：
  - **Anchor memory**：最早期的上下文证据（初始身份、颜色、位置）；
  - **Middle memory**：中间运动与交互历史的压缩；
  - **Recent memory**：预测前的立即状态；
  - **Global memory**：完整上下文的粗粒度摘要。
  - 采用时间角色嵌入，输出固定数量的记忆 token；若上下文掩码无法形成规则的时间管状布局，则退化为仅全局记忆。
- **门控交叉注意力读取**：在预设的读取层（实验中为第 3 层和第 7 层，零基索引）后，记忆寄存器通过门控交叉注意力从记忆库中读取信息，再携带该信息通过后续冻结的自注意力层传播给上下文 token 与未来掩码 token。门控初始化为保守值，使训练起始接近冻结预测器的原始行为。
- **寄存器分离设计**：工作空间寄存器仅参与预测器自注意力，记忆寄存器额外承担记忆读取功能。这种分离避免单一寄存器集混用"内部工作空间"与"显式记忆载体"两种角色。
- **训练方式**：仅训练记忆库、交叉注意力读取器与门控、工作空间寄存器、记忆寄存器（共 3.00M 参数）；V-JEPA 2 的编码器与主预测器块**完全冻结**。损失函数与基础模型相同，为 L1 未来潜在预测损失。评测协议完全保持一致，无额外分类器或阈值。

## 6. 主要结论与发现

- **主结果**：HERA with RRPM 在 IntPhys2 Main split 上将 V-JEPA 2-G 的成对 AvgSurprise 准确率从 **52.57% 提升至 54.35%**（+1.78 个百分点）。
- **与最强竞争对手 Direct-to-Target Memory 相比**：HERA 高出 0.79 个百分点，且只训练 3.00M 参数（对手为 5.96M），同时保持预测器主块完全冻结。
- **亚组提升显著**：
  - 固定相机连续性：46.15% → 57.69%（+11.54 点）；
  - 固定相机不变性：46.15% → 63.46%（+17.31 点）；
  - Hard 样例：48.81% → 57.74%；固定相机整体：48.56% → 56.73%；固态性：47.26% → 55.48%。
- **消融结论**：去掉记忆寄存器或工作空间寄存器任一组件均导致准确率从 53.95% 降至 53.56%，支持两类寄存器在训练好的 RRPM 中承担互补角色。
- **核心主张**："历史证据路由"是一种不同于"扩大存储"或"对象状态维护"的独立且有效的物理记忆组件：仅存储更多历史信息（Clip-Local、Prefix、Hierarchical）增益有限，共享寄存器次优，而分离检索与整合路径的设计最为有效。

## 8. 不足与局限

- **评测覆盖有限**：仅在 IntPhys2 单一基准上评估，未在 Physion、CLEVRER 等更多物理推理数据集或真实世界视频上验证，泛化性存疑。

- **应用限制**：方法针对遮挡下的物理预测这一特定问题设计，对于需要更长时程记忆（分钟级）或复杂因果推理（如多物体长时间交互）的场景，记忆规模与路由机制的可扩展性尚不清楚。
