## 摘要
世界动作模型（WAMs）通过预测所观察世界如何演变来学习与动作相关的表征。现有的大多数WAMs在RGB空间中定义这种未来，其中与任务相关的状态转换与纹理、光照、背景和视角中的干扰变化纠缠在一起。我们认为，WAMs应当显式地预测与动作相关的未来状态，而不是仅依赖RGB预测。我们引入了DreamWAM，它将未来预测重构为超越RGB的结构化世界建模，通过外观、运动、几何和语义的互补视图来表示未来状态。在训练过程中，DreamWAM将RGB和运动的联合潜在去噪与用于几何和语义的轻量级门控残差分支相结合。VideoDiT和ActionDiT之间的共享注意力使动作分支能够从这些未来状态预测中学习，而在推理时所有超越RGB的监督分支都被禁用，部署仍然仅使用RGB。在无展开和联合视频-动作推理两种情况下，DreamWAM在LIBERO上始终优于匹配的仅RGB基线，分别从97.30%提升到98.40%和从98.00%提升到98.90%。在未见过的LIBERO-Plus扰动下，提升更大，从51.36%提升到63.44%和从69.16%提升到75.47%。同样的鲁棒性也扩展到真实世界操作，在未见过的光照、背景和物体布局变化下，DreamWAM取得了74.4%的平均成功率，而Fast-WAM-Joint为55.6%。这些结果表明，鲁棒的世界动作学习不仅取决于预测未来，还取决于以一种对动作有意义的表示形式来表征未来。代码和模型已在https://github.com/hustvl/DreamWAM公开发布。

## Abstract
World Action Models (WAMs) learn action-relevant representations by predicting how the observed world will evolve. Most existing WAMs define this future in RGB space, where task-relevant state transitions are entangled with nuisance variations in texture, illumination, background, and viewpoint. We argue that WAMs should explicitly predict action-relevant future state rather than relying on RGB prediction alone. We introduce DreamWAM, which reformulates future prediction as structured world modeling beyond RGB, representing future states through complementary views of appearance, motion, geometry, and semantics. During training, DreamWAM combines joint latent denoising of RGB and motion with lightweight gated residual branches for geometry and semantics. Shared attention between VideoDiT and ActionDiT allows the action branch to learn from these future-state predictions, while all beyond-RGB supervision branches are disabled at inference and deployment remains RGB-only. Across both no-rollout and joint video-action inference, DreamWAM consistently improves the matched RGB-only baselines on LIBERO, from 97.30\% to 98.40\% and from 98.00\% to 98.90\%, respectively. The gains become larger under unseen LIBERO-Plus perturbations, from 51.36\% to 63.44\% and from 69.16\% to 75.47\%. The same robustness extends to real-world manipulation, where DreamWAM attains an average success rate of 74.4\% across unseen changes in lighting, background, and object layout, compared with 55.6\% for Fast-WAM-Joint. These results show that robust world-action learning depends not only on predicting the future, but on representing it in a form that matters for action. The code and models are publicly released at https://github.com/hustvl/DreamWAM.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：世界动作模型（World Action Models, WAMs）通过“预测未来”来学习与动作相关的表征。已有的 WAM（如 Fast-WAM、WorldVLA、Motus 等）主要将未来预测定义在 RGB 像素空间，利用视频生成骨干网络（Video DiT）联合动作扩散模型（Action DiT）进行训练。
- **核心问题**：仅用 RGB 预测未来存在根本性缺陷——与任务相关的状态变迁（如物体位移、接触、目标完成程度）与纹理、光照、背景、视角等任务无关的视觉变化相互纠缠。RGB 目标倾向于拟合视觉上显著的外观细节，而不一定显式保留决定动作成败的状态演化信息。
- **核心论点**：WAM 应当显式预测“对动作有意义的未来状态”，而不是仅仅渲染未来图像；即未来预测的**表示形式**本身是一个关键设计变量。论文提出“机器之梦（dream）”应包含外观、运动、几何和语义等多方面互补信息。
- **整体含义**：鲁棒的世界动作学习不仅取决于是否预测未来，更取决于**以什么样的形式表示未来**。通过训练时引入结构化多视角未来监督，可以显著提升策略在视觉分布偏移下的鲁棒性，同时部署时仍保持纯 RGB 接口。

## 2. 论文提出的方法论

### 2.1 核心思想
将未来预测重新定义为**超越 RGB 的结构化世界建模**，用四个互补视图描述未来状态：

- **外观（Appearance）**：未来 RGB 序列（由视频 VAE 编码的潜在表示）。
- **运动（Motion）**：相邻帧间的光流（RAFT 估计），经视频 VAE 编码，显式刻画时序变化。
- **几何（Geometry）**：由 Depth Anything V3 提取的深度结构特征，反映空间组织和相对位置。
- **语义（Semantics）**：由 DINOv2 提取的 patch 级特征，保持物体/区域级一致性。

这些视图视为“动作相关未来状态的相关投影”，而非完全解耦的独立因子或完整的物理描述。

### 2.2 异构未来建模：两条路径

- **路径一：RGB 与运动的联合潜在去噪**
  - RGB 与光流具有相同的稠密时空结构，因此在训练时将二者在同一 flow-matching 时间步上加噪，并在通道维度拼接：
    \[
    x_t^q = (1-t)z^q + t\epsilon^q,\quad q\in\{rgb, mot\},\quad x_t^{joint} = \text{Concat}_C[x_t^{rgb}, x_t^{mot}]
    \]
  - VideoDiT 在共享去噪流中同时学习两个视图，使运动成为显式预测目标。

- **路径二：几何与语义的门控残差建模**
  - 几何和语义特征来自外部编码器，并非 VAE 原生潜在空间，直接拼接会干扰预训练的视频生成先验。
  - 采用轻量级**门控残差分支**：保留原 VideoDiT 层输出作为主流，在各层添加受门控控制的修正项：
    \[
    \bar{h}^\ell = B^\ell(h^{\ell-1}),\quad h^\ell = \bar{h}^\ell + \sum_j g_j^\ell(\bar{h}^\ell,c)\odot R_j^\ell(\bar{h}^\ell),\quad \hat{f}_j = P_j(h^L)
    \]
  - 其中 \(R_j^\ell\) 生成视图特定残差，\(g_j^\ell\) 控制其幅度，\(P_j\) 预测对齐的未来特征。该设计使外部特征以“精炼”而非“替代”的方式融入预训练视频表示。

### 2.3 世界-动作耦合

- 沿用 Fast-WAM 的双专家架构：VideoDiT 建模未来状态，ActionDiT 去噪动作轨迹。
- 两专家通过**共享注意力**在配对层交换信息，使 ActionDiT 能直接利用 VideoDiT 中的多视图未来表示。
- 额外视图**并非孤立辅助任务**：它们重塑参与动作去噪的 VideoDiT 表示，从而直接影响动作学习。

### 2.4 训练目标与推理

- 总损失：
  \[
  \mathcal{L} = \lambda_{rgb}\mathcal{L}_{FM}^{rgb} + \lambda_{mot}\mathcal{L}_{FM}^{mot} + \lambda_{geo}\mathcal{L}_{pred}^{geo} + \lambda_{sem}\mathcal{L}_{pred}^{sem} + \lambda_{act}\mathcal{L}_{FM}^{act} + \lambda_g\mathcal{L}_{gate}
  \]
  - 其中包含门控正则化（ℓ1 惩罚）。
- **推理时**：所有 beyond-RGB 通路全部关闭——运动通道填零、门控残差分支与特征预测头移除、RAFT/DA3/DINOv2 不执行。最终只输出去噪后的动作块，保持与 Fast-WAM 完全一致的纯 RGB 部署接口。

## 6. 论文的主要结论与发现

- 在 LIBERO 上：
  - 无 rollout 模式：Fast-WAM 97.30% → DreamWAM-uncond 98.40%。
  - 联合模式：Fast-WAM-Joint 98.00% → DreamWAM 98.90%。
  - DreamWAM 为对比方法中最高平均分。
- 在 LIBERO-Plus 上：
  - 无 rollout 模式：51.36% → 63.44%（提升 12.08 个百分点）。
  - 联合模式：69.16% → 75.47%（提升 6.31 个百分点）。
  - 7 个扰动维度上两个模式下**全部提升**。
  - 无 rollout 到 joint 的差距从 17.80 缩小到 12.02，说明训练时的结构化未来监督使部分原本依赖测试时想象的未来结构被内化。
- 真实操作：
  - 标准任务平均成功率：90.8% → 96.7%。
  - 扰动任务平均成功率：55.6% → 74.4%（提升 18.8 个百分点）。
- 消融结论：
  - 三种辅助视图均有效，其中运动视图贡献最大；运动为几何/语义提供时间支架。
  - 路径匹配重要：运动应使用全去噪，几何/语义应使用门控残差。全去噪版本 D/D/D 甚至低于 RGB-only（98.00 → 97.85），而 D/R/R 达到 98.90%，证明“信息 + 正确路径”两者缺一不可。
- 总体结论：**鲁棒世界动作学习的关键不仅仅是预测未来，而是以对动作有意义的形式表示未来**。训练时结构化未来监督 + 推理时 RGB-only 部署，能在不增加部署开销的情况下显著提升分布外鲁棒性。

## 7. 优点

- **问题选择新颖且本质**：没有停留在“换更大模型/更多数据”，而是直接质疑 WAM 中“未来表示”这一根本变量。
- **设计优雅、部署友好**：所有额外监督只在训练时生效，推理保持纯 RGB，与现有 Fast-WAM 接口完全兼容，无额外在线计算成本。
- **异构建模策略合理**：对 VAE 对齐的运动采用联合去噪，对外部特征采用门控残差——理论动机清晰，消融验证了该策略的必要性。
- **实验维度全面**：两种推理模式、仿真 OOD 多维度扰动、真实机器人扰动、消融控制，形成了较完整的证据链。
- **代码/模型开放**：作者承诺公开代码和模型，可复现性强。
- **量化了“检索难题”**：通过 no-rollout 与 joint 的对比揭示结构化监督对策略本身的强化作用，不只是提升 rollout 质量。

## 8. 不足与局限
