## 摘要
当前视频世界模型在多智能体环境中表现不佳，因为它们将世界状态与视角相关的视觉潜变量纠缠在一起，导致计算冗余、视角不一致和可扩展性差。我们提出MAS（具有权威共享状态的多智能体世界模型）来解决这一限制。受多智能体游戏架构的启发，MAS将世界动力学与视角渲染解耦。一个学习到的逻辑引擎根据联合动作推进全局、权威的类型化状态，无需任何手写转换函数，并作为唯一的循环记忆和同步参考。从该共享状态出发，一个学习到的渲染引擎可按需为任何请求的视角生成独立且一致的视图。这种显式解耦使得MAS在匹配的多智能体Snake基准上，与最先进的多视角基线相比，实现了更高的状态准确性和更低的跨视角不一致性。它可推进包含1,024个并发玩家的预测世界达10,000个循环步骤。我们的结果表明，显式的权威状态建模为可扩展且一致的多智能体世界模拟提供了实用基础。

## Abstract
Current video world models struggle in multiplayer environments because they entangle world state with view-dependent visual latents, leading to redundant compute, view inconsistencies, and poor scalability. We propose MAS (Multiplayer world models with Authoritative Shared State) to resolve this limitation. Inspired by multiplayer game architectures, MAS disentangles world dynamics and view rendering. A learned Logic Engine advances a global, authoritative typed state from joint actions without any hand-written transition function, acting as the sole recurrent memory and synchronization reference. From this shared state, a learned Rendering Engine generates independent and consistent views for any requested camera on demand. This explicit disentangling allows MAS to achieve superior state accuracy and lower cross-view inconsistency compared to state-of-the-art multi-view baselines on a matched multiplayer Snake benchmark. It advances predicted worlds with 1,024 concurrent players for 10,000 recurrent steps. Our results show that explicit, authoritative state modeling provides a practical foundation for scalable and consistent multi-agent world simulation.

## 1. 核心问题与整体含义（研究动机与背景）

- **问题**：现有视频世界模型（如 GameNGen、Oasis、DIAMOND、Genie、WHAM）在单玩家场景中表现良好，但在多玩家环境中会将“世界状态”与“视角相关视觉潜变量”纠缠在一起，导致：
  - 同一世界内容被多个视角重复编码，计算冗余；
  - 不同视角对同一实体可能出现不一致的预测；
  - 模拟成本随观看视角数量增长，难以扩展到大量玩家。
- **背景**：现有多人世界模型（如 Gamma-World、MultiWorld、MultiGen、WanToFight）虽然引入了共享视觉表示或外部记忆，但依然没有使用“权威类型化状态”作为循环记忆和同步对象。
- **核心思路**：借鉴在线游戏中的“权威服务器 / 客户端呈现”架构，将世界动态预测与视图渲染解耦，学习一个可信赖的共享状态，再在此基础上按需渲染所有视角。

## 2. 提出的方法论：MASS

### 核心思想
- 将多玩家模拟建模为两步过程：
  1. **预测权威类型化共享状态**；
  2. **基于该状态进行相机条件渲染**。
- 同一个预测状态同时承担：
  - 循环记忆；
  - 客户端同步参考；
  - 所有视角图像的唯一来源。
- 训练/推理时完全不使用游戏自带的手写转换函数，世界推进完全由神经网络完成。

### 关键组件
- **World State Tokenizer**
  - 每个游戏通过一个 schema 声明实体类型、字段和数量；
  - 每个实体记录被编码为短 token 序列，包含记录本身、局部邻域上下文、关联玩家动作和外生输入；
  - 通过类型标签、固定位置和规范序列化保证无损解码；
  - 例如 Snake 中：全局记录 1 条、蛇记录 1,024 条、食物桶记录 4,096 条，共 5,121 条记录。
- **Logic Engine**
  - 一个 decoder-only Transformer（宽度 256、6 层、8 注意力头，约 5.66M 参数）；
  - 每次世界推进只运行一次，从联合动作和外部输入中生成下一状态；
  - 分解为逐记录自回归预测，自注意力限制在单条记录内部，记录之间通过“邻域窗口”传递交互信息；
  - Schema 派生掩码保证每个输出字段合法，同时用确定性选择器维护跨记录约束（如排序、唯一性）。
- **Rendering Engine**
  - 将共享状态通过相机局部投影转为 16 通道张量；
  - 使用残差 U-Net 生成 RGB 帧；
  - 每个视角独立解码，但都基于同一个预测状态，因此天然一致；
  - 相机数量、分辨率、画风可在推理时灵活改变，不需要重新训练世界动态模型。
- **服务器 / 客户端逻辑**
  - 服务器每 tick 发布一个版本化类型化快照；
  - 客户端收到快照后本地渲染；
  - 当服务器更新中断时，客户端可用同一 Logic Engine 本地推进状态，使用自己的动作并将其他玩家动作置为 no-op，保持本地响应。

## 3. 实验设计

### 数据集 / 场景
- **主基准（Matched Multiplayer Snake）**：
  - 48×48 竞技场，最多 8 个玩家槽位；

### 对比方法

## 7. 局限性与未来工作

### 局限性
- **状态 tokenizer 依赖手工定义 schema**：每个游戏都需要由人类声明实体类型、字段和数量，无法自动发现或学习，限制了直接迁移到陌生环境的便利性。
- **逻辑引擎的局部交互假设**：自注意力被限制在单条记录内部，跨记录交互依靠邻域窗口传递，难以建模长距离、全局或非局部耦合的动态（例如导弹跨越整个地图攻击目标）。
- **实验场景仍为 2D 网格游戏**：所有验证集中在 Snake 等简单战斗/控制类游戏；没有证据表明该方法可无缝过渡到 3D 物理世界或复杂真实环境。
- **渲染器能力相对有限**：轻量残差 U-Net 的图像质量与 SOTA 视频生成模型（如 GameNGen、Oasis）仍存在差距，高分辨率下可能有空间伪影。
- **训练数据分布偏差**：episode 由模拟器自动生成，动作序列大多遵循规则启发式，与人类玩家多样化的策略分布不一致，可能削弱模型在真实玩家交互下的泛化性。

### 未来工作
- **自动学习状态表示**：探索通过可微分推理或离散编码发现实体类型和字段，替代手工 schema。
- **扩展到 3D 与非网格环境**：尝试将类型化状态表示应用于物理仿真、机器人或开放世界 3D 游戏。
- **增强逻辑引擎**：引入全局注意力或层次化消息传递，以支持更长距离、更复杂的交互。
- **升级渲染管线**：结合条件生成模型或扩散模型，提升生成帧的视觉质量和细节。
- **与强化学习结合**：将权威状态作为可解释的观察空间，训练智能体进行规划、决策，甚至服务于“世界模型的模型”方向。
- **更公平的多尺度对比**：与参数量级相当的视频基线进行更多视角、更复杂环境的对照实验。

## 8. 对人类与领域的意义

MASS 提出的“权威类型化共享状态 + 相机条件渲染”范式，为多人世界模型提供了一条兼顾效率与一致性的新路线。它不仅将逻辑模拟的计算复杂度从视角数量中解耦，还使世界模型的状态可直接被外部策略、规划器或人机交互接口使用，有望推动游戏 AI、元宇宙仿真、多智能体协同等领域的发展。同时，该工作也明确揭示了当前神经世界模型在可解释性、可扩展性和自动化表示学习上的瓶颈，为后续研究提供了清晰的问题清单。
