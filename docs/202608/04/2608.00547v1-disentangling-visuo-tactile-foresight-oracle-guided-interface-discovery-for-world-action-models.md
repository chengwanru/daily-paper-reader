## 摘要
接触丰富的操作仍然具有挑战性，因为成功的控制依赖于通常仅从视觉中难以观测的物理交互线索。最近的触觉世界动作模型联合建模未来的视觉观测和触觉信号以指导动作生成，但如何为动作专家有效使用这些未来信息而构建其结构仍未得到充分探索。直接使用学习到的世界动作模型研究这一问题很困难，因为端到端行为纠缠了物理上无效的视觉未来、不可靠的预测、不准确或跨模态不一致的触觉预测，以及不可读的未来到动作接口。为使该接口可独立研究，我们提出了预言机视觉-触觉预见（OVTF），这是一个受控框架，提供来自模拟中验证的成功轨迹的配对RGB和触觉未来。通过固定未来提供者，OVTF隔离了接口并提出了一个更清晰的问题：如果未来是成功的且物理上可执行的，哪种表示允许动作专家吸收其益处？在OVTF内，我们提出了非对称相位局部未来记忆（AFM），其中视觉记忆读取未来视觉，每个触觉记忆联合关注其自身的触觉流和相位对齐的未来视觉，并阻断跨触觉访问。我们将AFM与模态隔离未来记忆（IFM）进行比较，后者移除视觉到触觉的访问并独立处理每个未来模态。在UniVTAC模拟基准的七个任务中，AFM实现了32.0%的平均成功率，而IFM为23.7%，UniVTAC-ACT为14.9%。这一受控比较表明，选择性的相位对齐视觉-触觉路由提供了比完全模态隔离更可操作的未来到动作桥梁。

## Abstract
Contact-rich manipulation remains challenging because successful control depends on physical interaction cues that are often weakly observable from vision alone. Recent tactile world action models jointly model future visual observations and tactile signals to guide action generation, but how such futures should be structured for effective use by the action expert remains underexplored. Directly studying this question with learned world action models is difficult because end-to-end behavior entangles physically invalid visual futures, unreliable predictions, inaccurate or cross-modally inconsistent tactile forecasts, and an unreadable future-to-action interface. To make this interface independently studyable, we introduce Oracle Visuo-Tactile Foresight (OVTF), a controlled framework that supplies paired RGB and tactile futures from successful trajectories verified in simulation. By fixing the future provider, OVTF isolates the interface and asks a cleaner question: if the future is successful and physically executable, what representation allows the action expert to absorb its benefit? Within OVTF, we propose Asymmetric Phase-Local Future Memory (AFM), in which visual memory reads future vision, each tactile memory jointly attends to its own tactile stream and phase-aligned future vision, and cross-tactile access is blocked. We compare AFM with Modality-Isolated Future Memory (IFM), which removes visual-to-tactile access and processes each future modality independently. Across seven tasks on the UniVTAC simulation benchmark, AFM achieves 32.0% average success, compared with 23.7% for IFM and 14.9% for UniVTAC-ACT. This controlled comparison shows that selective phase-aligned visual-tactile routing provides a more actionable future-to-action bridge than complete modality isolation.

## 1. 核心问题与研究动机

- 接触丰富操作（contact-rich manipulation）的成功控制高度依赖物理交互线索，而这些线索仅靠视觉往往难以充分观测，因此触觉信息至关重要。
- 现有“触觉世界动作模型”（tactile world action model, WAM）通过联合建模未来视觉观测与触觉信号来指导动作生成，但**未来信息如何结构化、如何让动作专家有效消费**这一“未来到动作接口”（future-to-action interface）问题仍未得到充分研究。
- 直接使用端到端学习的世界动作模型研究接口质量十分困难，因为最终分数混合了四类纠缠因素：
  1. 物理上无效的视觉未来预测；
  2. 动作分支对不可靠未来预测的信任不足；
  3. 触觉未来预测不准确或跨模态不一致；
  4. 未来到动作接口本身不可读。
- 因此，论文提出并回答一个更清晰的问题：**如果未来信息是成功且物理可执行的，什么样的接口表示能让动作专家真正吸收其益处？**

## 2. 方法论

- **OVTF 框架（Oracle Visuo-Tactile Foresight）**：
  - 不使用学习到的未来预测器，而是从模拟中验证成功的示范轨迹中采样**成对、时序对齐的 RGB 图像与左/右触觉 RGB 图像**作为“预言机”未来。
  - 未来内容不包括未来动作、未来 qpos、物体位姿等特权信息，仅含视觉和触觉观测。
  - 通过固定未来提供者，隔离并独立研究未来到动作接口的质量。

- **AFM 机制（Asymmetric Phase-Local Future Memory）**：
  - 使用 12 个可学习的 512 维槽位：4 个视觉槽、4 个左触觉槽、4 个右触觉槽。
  - 相位锚点固定为 {0.125, 0.375, 0.625, 0.875}，每个槽注意力分数由内容注意力加上高斯相位先验构成。
  - 路由规则为：视觉只读视觉；每个触觉槽联合关注**自身触觉流 + 相位对齐的未来视觉**；阻断左右触觉之间的交叉访问。
  - 未来视觉与触觉各由可训练的 ResNet-18 编码，并加入零初始化门控的深度可分离卷积残差，保证初始不扰动训练。
  - 所有未来槽乘以零初始化的 tanh 门控后注入 ACT 编码器内存，动作解码器用 50 个查询输出 50×8 的动作块。

- **IFM 对比机制（Modality-Isolated Future Memory）**：
  - 仅改变路由为完全模态隔离（视觉只读视觉、左触觉只读左触觉、右触觉只读右触觉），其余配置与 AFM 完全一致。
  - 通过 AFM 与 IFM 的对比，直接验证“相位对齐的视觉→触觉信息路由”是否比“模态隔离”更能帮助动作生成。

- **训练目标**：仅使用 masked action L1 loss，不训练 CVAE，当前观测编码器冻结，未来编码器与策略头可训练。

## 3. 实验设计

- **基准**：UniVTAC 模拟基准（UniVTAC-ACT* 为基准策略实现）。
- **任务**：七个接触丰富操作任务——
  - Put Shelf（放置置物架）
  - Pull Out Key（拔出钥匙）
  - Lift Bottle（提起瓶子）
  - Insert HDMI（插入 HDMI 线）
  - Insert Hole（插入孔）
  - Insert Tube（插入管）
  - Lift Can（提起易拉罐）
- **所有任务均使用左右双触觉流**；Insert Tube 和 Lift Can 使用头戴+腕部双视觉，其余任务使用头戴视觉。
- **对比条件**：
  - UniVTAC-ACT*（基线）
  - AFM Oracle（训练与评估都使用预言机未来 + 非对称路由）
  - IFM（仅路由改为模态隔离）
  - AFM Forced-Zero（使用 Oracle 训练好的模型，但在评估时将未来槽置零）
  - AFM Zero-Train（训练和评估都完全不使用未来数据，未来模块输入为字面零）
- **评估方式**：每个任务 50 个 rollout，共计 350 个 rollout；使用统一的任务成功判定、预处理、归一化、轨迹聚合等。

## 4. 资源与算力

- 模型训练使用 **2 张 NVIDIA RTX 4090 D 24GB GPU**。
- 每个任务训练 **2000 个优化步**；每 GPU micro-batch = 1，梯度累积 = 8，有效 batch size = 16。
- 优化器：AdamW，学习率 1e-5，权重衰减 1e-4；门控参数学习率 1e-3；余弦退火至 1e-6，梯度裁剪 1.0。
- 软件环境：Ubuntu 20.04.6，Intel i9-14900K，128GB 内存，PyTorch 2.7.0，Isaac Sim 4.5.0 等。
- 论文**未明确说明训练总时长**（小时数），但给出了模型规模、训练步数、GPU 数量等硬件信息。

## 5. 实验数量与充分性

- 共进行 5 种条件 × 7 个任务 = 35 组实验，每组 50 个 rollout，总计 1750 次评估（表内报告 350 次成功计数，实际每个条件对应 350 个 rollout）。
- 消融设计较完整：
  - 路由消融：AFM vs IFM（仅改变路由，其他全部固定）；
  - 未来信息有无：AFM Oracle vs AFM Forced-Zero vs AFM Zero-Train；
  - 基线对照：UniVTAC-ACT*。
- 公平性控制较好：所有 AFM 家族条件使用相同的任务映射、评估器、预处理、轨迹聚合、优先级、相机协议等，只允许改变与未来信息条件相关的最小适配。
- **充分性与客观性评价**：整体实验设计认真，控制了关键混淆变量，结论可信；但仅在一个仿真基准上测试、任务规模有限，且未报告多次运行方差，统计稳健性仍有提升空间。

## 6. 主要结论与发现

- **核心结果**：
  - AFM Oracle 平均成功率 **32.0%**（112/350）；
  - IFM 为 **23.7%**（83/350）；
  - UniVTAC-ACT* 基线为 **14.9%**（52/350）。
- **接口路由的重要性**：AFM 比 IFM 高 8.3 个百分点，表明**相位对齐的视觉→触觉选择性路由**比完全模态隔离更有利于动作生成。
- **未来信息确实被使用**：同一个 Oracle 训练好的模型，在评估时置零未来槽（Forced-Zero）后成功率降至 19.4%，说明模型训练过程中学会了利用测试时的未来内容。
- **无未来时性能依然稳健**：AFM Zero-Train 达到 20.0%，高于基线 14.9%，说明 AFM 兼容的策略路径即使在没有未来信息时也能保持良好表现。
- **任务级差异**：Put Shelf 和 Pull Out Key 对未来信息收益最大；Insert Tube 在 Oracle 和 Forced-Zero 下均为 42%，说明该任务主要受益于训练时分支的强化；Insert Hole 是唯一 IFM 最高的任务，但所有条件成功率普遍较低（≤8%）。

## 7. 优点

- **变量解耦设计**：OVTF 通过固定未来提供者，把“未来预测是否准确”与“未来到动作接口是否可用”解耦，使接口问题可独立、干净地研究。
- **受控比较公平性强**：AFM 与 IFM 之间仅改变路由边，未来内容、相位锚、内存预算、训练数据、优化预算完全一致，实验结果具有较强说服力。
- **Oracle 与 Zero 条件设计巧妙**：通过 Forced-Zero 和 Zero-Train 对照组，分别验证了“模型是否真的用未来”和“无未来时框架是否有害”，逻辑严谨。
- **方法创新点明确**：AFM 使用相位锚点 + 高斯软先验 + 不对称跨模态路由，结构简洁且有效；零初始化门控、深度可分离卷积残差等设计有助于稳定训练。
- **公开基准与代码友好**：基于 UniVTAC 基准和 ACT 实现，便于复现和后续扩展。

## 8. 不足与局限

- **预言机依赖**：OVTF 使用模拟成功轨迹作为理想化的未来提供者，真实场景没有这种“未来先知”，当实际未来预测存在错误时，AFM 的优势能否保持尚不明确。
- **实验范围有限**：仅在一个仿真基准（UniVTAC）上验证，未包含真实机器人实验，也未与其他最新的端到端世界动作模型进行直接横向比较。
- **跨触觉信息被完全阻断**：AFM 禁止左右触觉槽互相读取，可能忽略双手触觉协同信息；论文尚未验证是否可以从更灵活的路由中受益。
- **统计稳健性不足**：每个条件每个任务仅 50 次 rollout，未报告多次随机种子下的均值与方差，在低成功率任务（如 Insert Hole 仅 2-8%）上可能受到较大的随机波动影响。
- **训练步数偏低**：每个任务仅训练 2000 步，且未做更长训练或早停分析，最优性能可能未达到。
- **未来采样规则简单**：Oracle 未来是轨迹内均匀采样，未考虑动作窗口与技能阶段的对齐精度；最大采样帧数为 100，可能不足以覆盖长视野任务。
- **应用限制**：方法依赖已收集的成功示范轨迹，对轨迹覆盖率低或失败率高的任务，Oracle 前提可能不成立。
