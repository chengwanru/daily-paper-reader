## 摘要
从视频序列中预测未来状态是自主机器人系统面临的关键挑战，也是世界建模的基本目标。先前的生成方法在像素级别上运行，不可避免地过度强调与任务无关的细节，导致计算开销过大。虽然基于潜在空间的方法试图通过直接预测特征来缓解这一问题，但状态到任务映射中持续依赖重型解码器仍是计算瓶颈。在这项工作中，我们提出了无解码器特征预测（DF$^3$），一种全新框架，完全在潜在空间内建模世界演化并直接推导任务输出，从而完全消除了对解码器的需求。具体而言，DF$^3$ 将可学习的空间查询注入冻结的视觉基础模型的末端模块，以直接提取未来状态表示。通过采用轻量级、统一的运动感知上下文融合（MACF）机制，该机制将粗粒度光流扭曲与细粒度潜在交叉相关无缝集成，这些查询与历史token表示交互，以显式对齐并预测下一帧的特征。随后，一组专门的任务查询探测这些预测特征以执行下游任务。在公共基准上的大量实验以及在机器人模拟器中的零样本部署表明，DF$^3$ 实现了与最先进方法相当的性能，同时为集成感知与控制提供了卓越的效率和灵活性。

## Abstract
Forecasting future states from video sequences is a critical challenge for autonomous robotic systems and a fundamental objective of world modeling. Prior generative methods operating at the pixel level inevitably overemphasize task-irrelevant details, leading to prohibitive computational overhead. While latent-based approaches attempt to mitigate this by predicting features directly, the persistent reliance on heavy decoders for state-to-task mapping remains a computational bottleneck. In this work, we propose Decoder-Free Feature Forecasting (DF$^3$), a novel framework that models world evolution entirely within the latent space and directly derives task outputs, completely eliminating the need for a decoder. Specifically, DF$^3$ injects learnable spatial queries into the terminal blocks of a frozen vision foundation model to extract future state representations directly. By employing a lightweight, unified Motion-Aware Context Fusion (MACF) mechanism that seamlessly integrates coarse flow warping with fine-grained latent cross-correlation, these queries interact with historical token representations to explicitly align and forecast the feature of the next frame. Subsequently, a specialized set of task queries probes these forecasted features for the downstream task. Extensive experiments on public benchmarks and zero-shot deployment in a robotic simulator demonstrate that DF$^3$ achieves performance comparable to state-of-the-art methods while offering superior efficiency and flexibility for integrated perception and control.

- **问题背景**：从视频序列中预测未来状态是自主机器人系统（如自动驾驶）进行安全规划和控制的核心能力，也是世界建模（World Modeling）的基本目标。

  - **潜在空间预测方法**（如 DINO-WM、DINO-Foresight）：在语义特征空间中预测未来特征，减少了对无关细节的建模，但仍依赖重型 Transformer 解码器进行上下文建模，且还需要任务专用解码器将预测特征翻译为任务输出，计算瓶颈依然存在。
- **核心研究问题**：能否**完全在冻结的视觉基础模型（VFM）编码器内部**完成特征预测，从而彻底消除解码器？
- **本文答案**：提出 **DF³（Decoder-Free Feature Forecasting）**，将预测查询和任务查询直接注入冻结的 ViT 末端模块，在潜在空间内完成未来状态预测和下游任务输出，实现了完全无解码器的世界建模，兼具高效率和灵活性。

### 2. 方法论：核心思想、关键技术细节与公式

#### 总体架构
- 采用**冻结的 DINOv3-ViT-B/16**作为视觉基础模型骨干，权重完全冻结。
- 从较早层（L1）提取上下文特征（包含 patch tokens 和前缀 tokens，如全局类别 token、register tokens）。
- 向末端模块（L2）注入两类可学习查询：
  - **预测查询（Prediction Queries, Q_pred）**：预测下一帧的潜在特征。
  - **任务查询（Task Queries, Q_task）**：从预测特征中提取任务相关信息，通过轻量 MLP 头输出任务结果（如语义分割）。

#### 结构化查询注意力（Structured Query Attention）
- 在末端 Transformer 块中施加**非对称注意力掩码**，防止上下文 token 反向关注预测查询，避免信息泄漏，同时允许预测查询关注所有历史 token。

#### 运动感知上下文融合（MACF, Motion-Aware Context Fusion）
为赋予冻结图像编码器时序建模能力，设计了一个轻量级双分支融合模块：

- **光流扭曲分支（Flow-based Warp Branch）**：
  - 从预测查询预测密集光流场：Δp = MLP_flow(q_patch)
  - 用该光流将最近帧特征 f_L1(I_T) 扭曲到未来，生成粗对齐特征，提取提议更新方向：M_warp = MLP_warp(Ẽ_warp − q_patch)
- **潜在交叉相关分支（Latent Cross-Correlation Branch）**：
  - 在局部窗口内对相邻两帧特征进行软匹配（cosine 相似度 + softmax），得到历史运动矢量：V_hist = f_L1(I_T) − Σ softmax(sim_k/τ)·f_L1(I_{T−1})(k)
  - 经 MLP 投影为语义运动注入：M_xcorr = MLP_xcorr(V_hist)
- **动态融合（Dynamic Fusion）**：
  - 用学习的 sigmoid 门控机制融合两个分支的更新：f̂_L1(I_{T+1}) = q_patch + G(q_patch) ⊙ MLP_fuse([M_warp, M_xcorr])
  - 全局前缀 token 通过轻量时间外推器基于历史差分来预测。

#### 训练目标
- 全部使用**特征级监督**，不需要解码器联合训练：
  - **余弦相似度**项（对齐方向）+ **Huber 损失**项（稳定幅值）：
    - L_sim = E_t[1 − cos(F̂_L1(I_{t+1}), F_L1(I_{t+1})) + λ_huber · Huber(F̂_L1(I_{t+1}), F_L1(I_{t+1}))]
  - 对 patch tokens 和 prefix tokens 均计算损失。

### 6. 主要结论与发现

- DF³ **首次证明**了在冻结视觉基础模型的编码器空间内进行完全无解码器的未来特征预测是可行的。
- 在 Cityscapes 上，DF³ 的短期预测精度（mIoU 69.9 / MO-mIoU 68.7）与 DINO-Foresight（71.8 / 71.7）**基本相当**，中期预测（58.2 / 56.5 vs 59.8 / 57.6）差距在可接受范围内。
- **效率提升显著**：
  - FLOPs 降低 **36%**（1440.63 vs 2256.07 GFLOPs）
  - 推理时延降低 **70%**（292.4 ms vs 971.1 ms）
  - 峰值 GPU 内存降低 **67%**（3.1 GB vs 9.5 GB）
  - 预测参数减少 **41%**（177.0 MB vs 302.5 MB）
- **零样本跨实体部署成功**：在 Cityscapes 上训练的模型直接驱动 MATRiX 模拟器中的四足机器人，规划的轨迹与使用 Oracle 未来帧的轨迹高度对齐，验证了潜在表示的泛化性。
- 消融实验证实：光流扭曲和潜在交叉相关两个分支互补，结合后增益显著。

### 7. 优点（亮点）

1. **范式创新**：首次将无解码器思想（EoMT）引入世界建模/特征预测领域，突破了解码器瓶颈。
2. **编码器冻结**：VFM 权重完全冻结，只需训练查询和轻量融合模块，训练成本低且保留预训练语义表示。
3. **MACF 设计巧妙**：将粗粒度光流扭曲与细粒度潜在交叉相关相结合，为冻结编码器注入时序建模能力，是轻量高效的时序对齐方案。
4. **查询解耦**：预测查询与任务查询可独立训练、组合灵活，支持多任务共享预测特征。
5. **效率优异性突出**：在精度几乎不掉的情况下大幅削减计算开销，对实时部署至关重要。
6. **零样本跨实体验证**：从自动驾驶汽车视角迁移到四足机器人视角并成功规划导航轨迹，证明语义特征的跨实体泛化能力。

### 8. 不足与局限

1. **无动作条件预测**：当前 DF³ 仅支持观测驱动（observation-only）的未来预测，无法模拟特定动作的后果——这是闭环控制的关键能力，作者在 Limitations 中明确承认。
2. **空间分辨率受限**：在冻结 ViT 的降采样特征空间中预测，导致物体边界粗糙、细小结构模糊（空间过平滑），图 3 中肉眼可见边缘噪声。
3. **实验验证范围有限**：仅一个数据集（Cityscapes）、仅一个对比方法（DINO-Foresight）、无真实机器人部署（仅模拟器），证据强度有限。
4. **零样本部署存在视觉退化**：从汽车视角到四足机器人地面视角的跨域迁移导致预测特征明显粗糙和空间错位，虽然不影响轨迹规划，但视觉质量有待改进。
5. **中期预测精度下降明显**：从 T+1 到 T+3，mIoU 从 69.9 降至 58.2（下降 11.7），误差累积问题较突出。
6. **训练细节披露不足**：未报告批量大小、训练时长、消融实验的重复数等关键信息。
7. **对搜索半径敏感**：交叉相关搜索半径需要精细调优，半径过小（无法捕捉快速运动）或过大（引入噪声）都会导致性能下降。
