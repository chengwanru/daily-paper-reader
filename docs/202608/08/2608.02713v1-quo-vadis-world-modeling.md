## 摘要
持续改进的智能体需要超越静态监督的动态交互反馈，然而直接与现实环境交互成本高昂、速度缓慢、不安全且难以并行化。世界建模提供了一种自然的中间代理，使智能体在采取真实行动之前能够查询成本更低、更可控的反馈。经典世界模型主要通过未来物理状态预测来实现这种代理，这种表述对需要超越原始状态转移的可操作反馈的智能体而言，虽有用但过于狭窄。在这项工作中，我们提出了“以智能体为中心的交互式世界代理”的概念，将基本范式从物理状态转移转变为智能体可用的信息转移，例如执行结果、检索到的经验或技能以及验证信号，从而拓宽世界建模的范围，为持续改进的智能体提供多样化的反馈。为了系统性地描绘这一设计空间，我们将世界代理根据其反馈模态组织为六种功能形式：动态代理、空间代理、执行代理、记忆/经验代理、技能代理和奖励/验证代理，它们共同刻画了世界建模服务于智能体改进的主要方式。我们进一步分析了这些代理如何在三个递进层级上赋能智能体：L.1 推理时引导（Inference-Time Guidance），即代理输出丰富上下文信息以做出更优决策；L.2 训练时优化（Training-Time Optimization），即代理输出产生奖励、批评或合成轨迹用于策略学习；以及 L.3 智能体-代理协同进化（Agent-Proxy Co-Evolution），即真实环境证据持续更新代理与智能体，实现协同进化。最终，这项工作将世界建模重塑为以智能体为中心的范式，为构建能够赋能智能体更好地规划、更快地学习并持续进化的世界代理绘制了路线图。

## Abstract
Continually improving agents require dynamic interaction feedback beyond static supervision, yet direct real-environment interaction is costly, slow, unsafe, and hard to parallelize. World modeling offers a natural intermediate proxy that allows agents to query lower-cost, more controllable feedback before committing to real actions. Classical world models instantiate this proxy primarily through future physical-state prediction, a formulation useful yet narrow for agents that require actionable feedback beyond raw state transitions. In this work, we conceptualize Agent-Centric Interactive World Proxies, shifting the fundamental paradigm from physical state transitions to agent-usable information transitions, such as execution outcomes, retrieved experiences or skills, and verification signals, broadening the scope of world modeling to provide versatile feedback for continually improving agents. To systematically map this design space, we organize world proxies into six functional forms based on their feedback modalities: dynamics, spatial, execution, memory/experience, skill, and reward/verification proxies, which together characterize the primary ways world modeling serves agent improvement. We further analyze how these proxies empower agents across three progressive levels: L.1 Inference-Time Guidance, where proxy outputs enrich in-context information for superior decisions; L.2 Training-Time Optimization, where proxy outputs yield rewards, critiques, or synthetic rollouts for policy learning; and L.3 Agent-Proxy Co-Evolution, where real-environment evidence continuously updates both the proxy and the agent for co-evolution. Ultimately, this work recasts world modeling into an agent-centric paradigm, establishing a roadmap for building world proxies that empower agents to plan better, learn faster, and evolve continually.

## 2. 论文提出的方法论

### 2.1 核心概念：从 World Model 到 World Proxy

论文在三个轴向上对经典世界模型做了推广（Table 2）：

| 维度 | 从（经典） | 到（本文） |
|------|-----------|-----------|

### 2.2 形式化定义

$$\hat{s}_{\ell+1} = \mathcal{WP}(s_\ell, u^\mathcal{F}_\ell), \quad s_\ell \in \mathcal{S}$$

其中：$\ell$ 为交互步；$\mathcal{S}$ 为广义信息状态空间（含物理状态、观测、记忆、知识、执行结果、验证信号等）；$\mathcal{F}$ 为代理函数（六类）；$u^\mathcal{F}_\ell$ 为智能体主动提出的查询/动作/干预；$\hat{s}_{\ell+1}$ 为代理返回的反馈。

闭环流程为四步循环：**Agent 提出交互 → World Proxy 预测信息转移 → 反馈返回 Agent → Agent 利用反馈改进**。

### 2.3 六类功能形式（Proxy Functions）

1. **Dynamics Proxy（动力学代理）**：经典世界模型的形式，预测未来状态和奖励，如视频预测、动作条件生成、机器人动力学、基于模型的强化学习；
2. **Spatial Proxy（空间代理）**：根据查询的视角/位姿生成该视角下的观测，如 NeRF、3D Gaussian Splatting、新视角合成、导航中的空间想象；
3. **Execution Proxy（执行代理）**：模拟可执行交互的结果（代码运行输出、浏览器点击后的页面状态、API 调用返回），如 Web 交互模拟器、代码执行预测器；
4. **Memory/Experience Proxy（记忆/经验代理）**：检索与当前任务相关的历史经验、失败案例、约束条件；
5. **Skill Proxy（技能代理）**：推荐或检索可复用的行为知识、工具使用例程、技能库；
6. **Reward/Verification Proxy（奖励/验证代理）**：评估智能体行为/轨迹/答案，提供奖励、验证结果、批评、偏好或失败原因。

### 2.4 三个赋能层级（Empowerment Levels）

- **L.1 Inference-Time Guidance（推理时引导）**：代理输出作为上下文增强，加入智能体当前上下文 $\hat{s}_{guid\ell+1}$，支撑更优决策。不改变智能体参数，成本低、可逆。例如：网页智能体在点击"购买"前先想象结果页面。
- **L.2 Training-Time Optimization（训练时优化）**：代理输出作为训练信号（奖励、批评、偏好对、合成 rollout），通过 SFT、DPO、PPO、GRPO 等优化策略。代理从"推理时顾问"升级为"训练时的裁判/教师/模拟器"。
- **L.3 Agent-Proxy Co-Evolution（共同进化）**：真实环境的轨迹、失败、新发现更新代理，代理知识又被蒸馏回智能体，实现闭环协同进化。形式化 $(\text{agent}^+, \mathcal{WP}^+) = \text{CoEvolve}(\text{agent}, \mathcal{WP}, \hat{s}^{\text{proxy}}_{\ell+1}, s^{\text{env}}_{\ell+1})$。

## 6. 论文的主要结论与发现

1. **范式转移**：世界建模的目标应从"尽可能忠实预测世界"转向"服务智能体的持续改进"——判断标准不是视觉保真度或预测精度，而是**可操作的信息增益（actionable information gain）**。
2. **统一设计空间**：六种功能代理（dynamics、spatial、execution、memory、skill、reward/verification）与三层赋能级别（L1 推理时指导、L2 训练时优化、L3 协同进化）构成两张正交轴，覆盖了世界建模服务智能体改进的完整设计空间。
3. **智能体-代理协同进化是最高的承诺级别**：L3 不仅让代理更好地服务智能体，还让两者相互塑造——真实环境证据维护代理的可靠性，而代理又不断为智能体提供训练和验证信号，两者形成闭环。
4. **开放挑战**（论文明确列出四点）：
   - **保真度与想象的极限**：生成模型可能生成看似合理但违反真实动态的内容，错误长程 rollout 累积，需要校准的不确定性而非更锐利的像素；
   - **何时信任代理**：智能体需要在线判断是采用代理反馈还是回归真实环境，当前智能体缺乏这种判断力；
   - **奖励攻击（reward hacking）与安全性**：代理作为奖励/验证器（L2）时可能被利用盲点；
   - **评估需要衡量信息增益**：现有 benchmark 衡量代理的孤立能力（如 realism、fidelity），而非"反馈是否帮助智能体规划/学习/改进"。
