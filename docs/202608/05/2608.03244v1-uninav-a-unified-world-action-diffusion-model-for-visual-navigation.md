## 摘要
图像目标视觉导航是具身代理的基本能力。现有的导航策略能够有效预测航点轨迹，但缺乏视觉预见性；而导航世界模型可以预测未来观察，但通常需要昂贵的规划展开。我们提出了UniNav，一种统一的世界-动作模型，通过单一的扩散过程生成未来的视觉观察和连续的航点轨迹。给定历史帧和目标图像，UniNav在单个Transformer中共同去噪视觉和航点令牌，在共享框架中统一未来预测和动作生成。为了改善空间基础，我们加入了几何感知的相机令牌。我们还同时使用带有轨迹标注的导航数据和仅视频数据进行训练，使模型能够从没有航点标注的多样化视频中受益。基于这一统一框架，我们引入了两种变体：UniNav-Full联合预测可解释的未来观察及其对应轨迹，而UniNav-Fast在推理时移除未来图像令牌以进行高效轨迹预测。在导航基准上的实验表明，UniNav在所有数据集上的ATE均优于最强基线。通过一步推理，UniNav-Fast实现了0.1秒的延迟，且没有明显的精度下降。代码将发布。

## Abstract
Image-goal visual navigation is a fundamental capability for embodied agents. Existing navigation policies efficiently predict waypoint trajectories but lack visual foresight, while navigation world models can anticipate future observations but often require costly planning rollouts. We present UniNav, a unified world-action model that generates future visual observations and continuous waypoint trajectories through a single diffusion process. Given history frames and a goal image, UniNav jointly denoises visual and waypoint tokens within a single transformer, unifying future prediction and action generation in a shared framework. To improve spatial grounding, we incorporate geometry-aware camera tokens. We also train on both trajectory-labeled navigation data and video-only data, enabling the model to benefit from diverse videos without waypoint annotations. Based on this unified framework, we introduce two variants: UniNav-Full jointly predicts interpretable future observations and their corresponding trajectories, while UniNav-Fast removes future-image tokens at inference for efficient trajectory prediction. Experiments on navigation benchmarks show that UniNav outperforms the strongest baseline in ATE across all datasets. With one-step inference, UniNav-Fast achieves a latency of 0.1s without a substantial accuracy drop. Code will be released.

## 1. 论文的核心问题与整体含义

- **研究背景**：图像目标视觉导航要求智能体根据观察历史与目标图像预测未来的局部航点轨迹，以到达目标位置。该任务构成了具身智能体视觉导航的基础能力。
- **现有方法的核心矛盾**：
  - **纯策略模型**（如 GNM、ViNT、NoMaD）：能够高效地从观测直接预测航点轨迹，但缺乏对人类导航天然伴随的“视觉前瞻”能力的建模，即无法想象未来视角下的场景变化，因此可解释性差，也难以在预期视觉变化的基础上做规划。
  - **导航世界模型**（如 NWM）：能够生成未来观测，但采用“先生成-后评估”的范式，需要对每个候选轨迹分别做视频回滚，计算成本随候选轨迹数量急剧增长，难以实现实时闭环导航。
- **论文的核心思路**：借鉴机器人操作领域近年来兴起的统一世界-动作模型（Unified World-Action Model），将“未来视觉预测”和“动作/航点生成”统一到一个单一的扩散生成过程中，兼顾视觉前瞻的可解释性与实时行动的效率。

## 2. 方法论

- **模型整体架构**：UniNav 基于预训练的 Wan2.1-T2V-1.3B 视频扩散 Transformer（Wang et al., 2025）构建，将未来视觉潜在表示、连续航点轨迹和相机几何信息组织成一个异构的 token 序列，在共享 Transformer 中通过统一的流匹配（Flow Matching）目标联合去噪。
- **异构 Token 序列**：统一序列组织为 `[h_cam | h_pred | h_traj | h_hist | h_goal | h_reg]`，包括：
  - **视觉 token**：由冻结的视频 VAE 编码历史帧、目标图像与带噪未来帧。
  - **航点 token**：将 K 步局部航点经 MLP 投影到 Transformer 隐藏空间，由轨迹头部解码出轨迹流向量。
  - **相机 token**：由冻结的几何基础模型（Depth Anything 3）从历史帧和未来帧中提取，提供每个未来视角的紧凑 3D 几何目标。
  - **寄存器 token**：一组可学习的 token，促进异构 token 间的全局信息交换。
  - 视觉 token 保留预训练模型的位置编码，非视觉 token 使用恒等位置编码以避免施加人为空间坐标。
- **统一流匹配目标**：对每种模态 m ∈ {vid, traj, cam}，带噪状态与目标速度定义为：
  - z_m = (1 − σ_m)x_m + σ_mε_m；u_m = ε_m − x_m
  - 总损失为：`L = λ_vid·m_vid·L_vid + λ_traj·m_traj·L_traj + λ_cam·m_cam·L_cam`
  - 视频损失与相机损失为 L2 范数，轨迹损失使用 SmoothL1 损失；m 指示该样本是否提供对应模态监督。
- **混合训练策略**：同时使用带轨迹标注的导航数据（三个目标均启用）与纯视频数据（关闭轨迹损失），使模型能够从大规模无标注视频中获取视觉与几何监督。
- **两个变体**：
  - **UniNav-Full**：使用完整 token 序列，迭代去噪同时生成未来观测与对应轨迹，提供可解释的视觉前瞻。
  - **UniNav-Fast**：训练时对非未来 token 施加非对称注意力掩码（未来 token 可以看其他 token，但其他 token 不能看未来 token），使轨迹去噪不依赖未来图像表示；推理时直接移除未来图像 token，跳过视频生成与 VAE 解码，显著降低延迟。

## 3. 实验设计

- **导航数据集（带轨迹标注）**：RECON、SaCSoN、GO Stanford、SCAND，四个真实世界图像目标导航基准。
- **纯视频数据集（无动作标注）**：ScanNet、DL3DV、CityWalker、LAVN，用于混合训练。
- **预配置**：3 帧历史、预测 6 个未来帧与 6 个航点，分辨率 256×192。
- **评估指标**：
  - 航点预测：ATE（绝对轨迹误差）、RPE（相对位姿误差）。
  - 未来帧质量：PSNR、SSIM、LPIPS。
  - 效率：模型延迟（Latency）与函数评估次数（NFE）。
- **对比方法**：
  - 纯动作策略：ViNT、NoMaD、NavDP、FlowNav。
  - 世界模型：NWM。
- **主要结果**：在只用轨迹标注导航数据（不使用额外视频数据）的设置下，UniNav 在全部四个数据集上 ATE 均优于最强基线，降幅分别为 RECON -3.7%、SaCSoN -24.7%、GO Stanford -18.2%、SCAND -6.8%；RPE 也在多数数据集上具有竞争力。
- **消融实验**（在 RECON 上）：
  - 相机几何监督的设计选择：对比去除相机 token、干净相机 token 条件（oracle 上界）、相机 token 去噪三种设置。
  - 混合数据训练效果：在有无相机 token 去噪两种条件下分别对比是否加入纯视频数据，揭示相机几何监督是视频数据有效迁移到航点预测的关键。
- **效率/精度分析**：不同去噪步数（1/2/5/10/20/50 步）下的 ATE/RPE/延迟对比，以及与 NWM 的约 900 秒/12000 NFE 的对比。

## 6. 主要结论与发现

- **统一建模有效提升动作预测**：联合建模未来视觉动态与航点动作可改善各数据集上的航点预测精度，说明视觉前瞻对动作预测有正向作用。
- **相机几何监督是视频数据可用的关键**：仅加入纯视频数据而不带相机 token 去噪，反而使 ATE 上升 +0.009；加入相机 token 去噪后，视频数据使 ATE 和 RPE 均降低 0.012。这说明几何监督为视觉动态与导航动作提供了有效的“桥接”信号。
- **效率优势显著**：UniNav-Fast 一步推理延迟仅 0.109 秒，两步推理 0.212 秒，远低于 NWM 的约 900 秒规划开销，且精度几乎不降，适合在线导航部署。
- **不单调的步数效应**：增加去噪步数不总是带来增益，50 步时 UniNav-Fast 精度反而较 20 步下降（ATE 从 0.300 升至 0.331），提示存在最佳步数区间。

## 7. 优点

- **范式创新**：将世界模型与策略模型统一为单一扩散生成过程，避免了生成-评估式世界模型的高昂规划回滚成本，同时保留了视觉前瞻能力，兼具可解释性与实时性。
- **几何感知设计新颖**：将几何基础模型提取的相机 token 作为辅助去噪目标，既显式注入 3D 结构监督，又避免在推理时依赖未来观测（干净相机 token 条件是 oracle，不可部署），是实用且有效的折中。
- **数据效率思路好**：通过相机 token 监督使纯视频数据能够为动作预测服务，缓解了轨迹标注数据的稀缺瓶颈。
- **双变体设计灵活**：UniNav-Full 面向可解释的联合预测，UniNav-Fast 面向实时高效执行；通过非对称注意力在训练时保留视觉监督、在推理时解耦图像 token，设计精巧。
- **利用预训练视频扩散模型**：从大规模预训练视频生成模型中迁移强视觉先验，符合基础模型范式的发展趋势。
- **实验证据扎实**：在多个真实世界数据集上一致超越基线，消融实验能够清楚说明各设计组件各自的贡献。
