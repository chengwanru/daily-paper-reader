## 摘要
尽管世界-动作模型（WAM）通过在动作前预测视觉演化来增强长时程机器人控制，但长时程可靠性要求在真实观测中反复重新锚定，而非递归式展开。现有WAM通过在每个片段之间用真实数据刷新历史或KV缓存来解决这一问题。然而，这种分块反馈以较粗的时间粒度运行，因此无法在单个时间步层面修正预测误差。为此，我们提出反馈流匹配（FBFM），一种无训练的推理机制，将重新锚定推入主动生成的片段内部。在流匹配过程中，FBFM对条件速度场应用掩码伪逆修正：它利用前一个动作片段指导下一个动作片段的生成，并使用执行前一个片段后观测到的图像指导下一帧预测。这种跨片段配对——一个片段的反馈及时到达并塑造下一个片段——形成了异步循环，无需等待片段边界即可修正误差。由于无需训练，该机制增强了对意外事件的响应性，并抑制了长时程任务中的漂移。我们在联合生成WAM（DreamZero）和分阶段WAM（LingBot-VA）上评估FBFM。在选定的LIBERO和RoboTwin2.0任务中，它在有利设置下将成功率提高了5%以上，且真实机器人观测-预测诊断显示出显著更好的跟踪效果。我们认为FBFM为细粒度在线修正提供了一种新范式，桥接了开环流生成与闭环真实世界动态。

## Abstract
Although world-action models (WAMs) enhance long-horizon robot control by predicting visual evolution before acting, long-horizon reliability demands repeated re-grounding in real observations--not recursive rollout. Existing WAMs address this by refreshing history or KV cache with ground-truth data between chunks. However, such chunk-wise feedback operates at a coarse temporal granularity and thus fails to correct prediction errors at the individual time-step level. To address this, we propose Feedback Flow Matching (FBFM), a training-free inference mechanism that pushes re-grounding inside the actively generated chunk. During flow matching, FBFM applies a masked pseudoinverse correction to the conditional velocity field: it leverages the preceding action chunk to guide generation of the next action chunk, and uses the image observed after executing that preceding chunk to guide the next frame prediction. This cross-chunk pairing--where feedback from one chunk arrives in time to shape the next--creates an asynchronous loop that corrects errors without waiting for chunk boundaries. Being training-free, the mechanism improves responsiveness to unexpected events and suppresses drift in long-horizon tasks. We evaluate FBFM on both a joint-generation WAM (DreamZero) and a stage-wise WAM (LingBot-VA). On selected LIBERO and RoboTwin2.0 tasks, it improves success rates by over 5% in favorable settings, and real-world robot observation-prediction diagnostics show notably better tracking. We argue that FBFM offers a new paradigm for fine-grained online correction, bridging open-loop flow generation with closed-loop real-world dynamics.

  - 已被环境揭示的时槽应锚定到其测量值；

## 2. 提出的方法论：核心思想、关键技术细节与公式/算法流程

### 2.1 核心思想

FBFM 将状态反馈和跨片段动作一致性统一表达为流匹配过程上的**时间对齐约束**，在推理时将反馈注入到活跃生成片段的内部：

- **动态状态反馈**：每个求解器求值（solver evaluation）时，新获得的潜在状态通过动态更新的目标与掩码暴露给活跃片段；
- **跨片段动作一致性**：前一片段已提交的动作在重叠区域定义固定目标；
- 二者共享同一数学接口（掩码伪逆引导），但语义不同——前者引入新测量的物理转移，后者保持控制器已做出的承诺。

### 2.2 关键技术细节

**（1）问题设定与符号**

- 环境建模为可控马尔可夫过程 M = (S, A, P)，潜在状态 zt = E(O(st))；
- WAM 预测未来潜在状态块 Zt 和动作块 At；
- 线性条件概率路径：Xτt = (1-τ)ϵ + τXt，条件目标速度 u(Xτt|Xt) = Xt − ϵ；
- 推理时从噪声求解 ODE：dXτt/dτ = vθ(Xτt, τ; Ht)。

**（2）统一伪逆引导修正公式**

在每次求解器求值时，FBFM 使用统一的引导场：

```
vQ_FBFM = v̄Q_t,k + λQ_τ (JQ_t,k)^T P_Q W_Q,t,k (Y_Q,t,k − X̂1_t,k)
```

其中：
- v̄ 为冻结模型的原速度场输出；
- X̂1_t,k = X^{τk}_t + (1−τk)·v̄ 为预测的干净端点（clean endpoint）；
- J 为端点关于当前噪声样本的雅可比矩阵；
- W 为选择/置信加权的掩码算子，P 为模态预条件算子；
- λ 为随流时间变化的引导强度。

**（3）分阶段 WAM（stage-wise）中的实例化**

- **状态流**：动态接收执行过程中新编码的真实潜在状态，激活对应掩码，通过式（19）约束正在进行的状态生成——实现“硬状态修补”；
- **动作流**：
  - 状态上下文刷新：将最新反馈与已生成状态端点融合，构造修正后的状态上下文条件动作生成；
  - 先前动作一致性：前一片段在重叠区域的动作作为固定目标，直接约束新动作流的对应坐标。

**（4）联合生成 WAM（joint-generation）中的实例化**

- 状态与动作目标组装为联合约束：

```
YX = [YZ; YA]，WX = blkdiag(WZ, WA)
```

- **关键优势**：通过联合端点雅可比矩阵的跨模态分块（JZA ≠ 0），状态残差可以在同一求解器步骤中**直接修正动作坐标**，无需等待上下文传递。即：

```
gA = (JZA)^T eZ（当动作残差为零时）
```

### 2.3 训练无关性

- 模型参数完全冻结，仅改变推理时的向量场和条件上下文；
- VJP（vector-Jacobian product）通过自动微分实现；
- 不要求环境步与求解器步的固定比例，仅要求反馈在对应求解器求值前可见。

## 6. 主要结论与发现

1. **LingBot-VA/RoboTwin2.0 分阶段 WAM**：FBFM 使 Clean 和 Randomized 成功率分别提高2.86和3.10个百分点，总体增益2.98个百分点——在42个Clean任务单元中改善19个，Randomized中改善15个；表明推理时反馈在分阶段 WAM 执行中有效。
2. **机制验证**：FBFM 将波0下一状态潜在MSE从0.6828降至0.6751（−1.13%）；仅切换 RTC/FBFM 缓存即改变归一化新动作RMS 0.00890（为重复底数的7.39倍），速度RMS在所有51步中高于重复底数（AUC比2.52×）——验证了“状态反馈→潜在预测→动作速度场”的预设路径。
3. **DreamZero/LIBERO 联合 WAM**：LIBERO-Goal 和 LIBERO-10 各提高2.5个百分点，但 Spatial 和 Object 分别下降1.5和1.0个百分点；总池化提高0.625个百分点——**结论为适度整体增益加异构套件级效应**，并非均匀提升。原因可能是 DreamZero 的加速推理设计（多次求解器更新复用同一原生模型评估）削弱了反馈即时效果，以及联合反馈对状态/动作残差相对尺度敏感。
4. **真实世界视频预测**：FBFM 将 MAE 从9.63降至9.27、PSNR 从20.06提高到23.10 dB，更好地保持球位置等任务相关物理信息——表明 FBFM 能超越开环预测约束物理上有意义的视觉演化。
5. **附加发现**：当状态反馈仅覆盖有限前缀时（10/20时槽），有限反馈视界结束后出现大面积伪影，与反馈覆盖时长紧密相关；作者将该现象归因于 Wan2.2 特有的编码器/骨干不匹配假设，留作未来工作。

## 7. 优点：方法与实验设计中的亮点

1. **训练无关性**：模型参数完全冻结，通过 VJP 计算实现引导；兼容任意预训练 WAM，无需额外训练数据或模块；
2. **细粒度在线修正**：首次将反馈注入活跃生成片段内部的单时间步层面，克服了分块级刷新的粒度限制；
3. **统一数学接口**：状态反馈与跨片段动作一致性共享同一掩码伪逆引导形式，但语义有别；可同时适用于分阶段和联合生成两种主流 WAM 架构，且在联合生成中天然获得状态→动作的直接修正路径；
4. **异步执行窗口的巧妙利用**：利用执行与生成的时域重叠将 WAM 推理形式化为动态部分可观测生成问题，概念清晰且工程可落地；
5. **实验控制严格**：同一架构内三种掩码模式共享检查点、噪声、求解预算和伪随机时钟；机制诊断设计了缓存切换与重复底数对照，剥离出状态反馈对动作生成的因果链路；
6. **超参搜索透明**：在附录中记录完整搜索历史，明确报告未执行的计划点，对历史跨机器对比谨慎处理；
7. **代码可追溯性管理**：提供具体提交哈希、分支路径和审计记录，便于复现与验证。

## 8. 不足与局限

1. **DreamZero 提升有限且不均匀**：总体增益小，两个套件出现退化；作者认为与加速推理中缓存复用导致的反馈延迟和模态尺度敏感性有关，但缺乏更系统的机制分析和改进方案；
2. **统计显著性不足**：kp 扩展比较的点估计最佳值未达到0.05显著性水平；主要结果缺乏置信区间或显著性检验；
3. **对齐坐标近似假设**：使用 h†(h(X̂)) ≈ X̂ 在掩码选择的反馈子空间上近似成立，对任意非线性编码-解码对不保证成立；
4. **推理开销**：VJP 计算和反馈管理增加推理时计算负担，实时闭环部署需要进一步工程优化；
5. **真实世界评估有限**：物理机器人实验仅为开环观测预测诊断（视频预测），并非完整真实机器人闭环控制策略，不能直接证明真实环境下任务成功率的提升；
6. **Wan2.2 有限前缀反馈下的伪影问题**：当反馈仅覆盖部分视频时，反馈视界结束后产生大面积视觉损坏，机制未完全理解（仅提出假设）；
7. **基准覆盖不全面**：LIBERO-90 被排除；RoboTwin2.0 仅选定了42个任务，更长程任务未包含在主评估中；
8. **执行细节标注不完整**：部分实现未冻结到已发布提交；偶有跨机器性能对比（A6000 vs Pro6000）；CPU/GPU 渲染被视为等效后端但来源不同；混合多实验记录；
9. **实际异步性依赖实验配置**：反馈时序由确定性伪异步时钟控制，实际壁钟延迟下的效果可能不同；真实系统部署还需同步边界处理。
