## 摘要
许多最近的机器人策略通过使用大型预训练视觉-语言模型（VLM）作为动作骨干来追求更强的控制能力。我们引入了WorldDiT，一种统一的扩散Transformer架构，它将动作生成与视觉世界建模相结合，并且在没有大型预训练VLM动作骨干的情况下实现了强劲的性能。在训练过程中，一个单一的扩散Transformer生成连续的动作块，并从未来的相机帧预测归一化的RGB补丁目标。在四个LIBERO仿真套件中，WorldDiT位于报告的帕累托前沿上，兼顾总模型参数和在报告所有四个套件的方法中的平均成功率。这些结果为未来的规模扩展研究提供了一个强大的亚十亿参数基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

## 方法论：核心思想与关键技术

**核心思想：**
- 使用**一个共享的DiT（Diffusion Transformer）骨干**同时建模两件事：连续机器人动作和从未来相机帧中选取的归一化RGB patch。
- 未来RGB patch预测**仅在训练时提供辅助监督**，推理时完全不参与计算图，保持纯动作生成路径。

**技术架构与关键细节：**

1. **多模态token化：**
   - 冻结的MAE图像编码器 + 共享Perceiver Resampler处理多视角RGB观测（主相机+腕部相机）。
   - 冻结的CLIP文本编码器处理语言指令。
   - 可训练的机器人状态编码器分别编码手臂和夹爪，拼接后投影为一个状态token。
   - 所有token连接后作为DiT骨干的条件输入。

2. **观测窗口与目标构造：**
   - 轨迹窗口包含 N=10 步，前 C=3 步为观测上下文。
   - 动作目标为 H=7 步的动作块：A_𝑖 ∈ ℝ^{7×7}。
   - 未来RGB patch目标：每个224×224的CLIP预处理帧分为16×16个patch，每个patch向量（768维）用自身均值和方差归一化，每个相机保留64个均匀间隔的patch，两相机共128个patch tokens。目标来自时间偏移H处的帧（即 i+H）。

3. **Flow Matching 训练：**
   - 目标：回归从高斯噪声到干净目标的直线路径的velocity。
   - 对动作和目标RGB patch均采用统一的目标函数：
   - **L_flow = 𝔼[‖v_θ(x_τ, τ, c) − (y − ε)‖²]**
   - 总损失为动作velocity损失与RGB patch velocity损失的加权和：**L_total = w_action L_action_flow + w_rgb L_rgb_flow**
   - 损失权重分别为0.1和0.001。

4. **推理流程：**
   - 从高斯噪声初始化动作token，用20步Euler积分求解velocity场τ∈[0,1]。
   - 解码动作块，执行前3个动作，更新上下文窗口，重新规划（receding-horizon控制）。
   - 使用时序集成（temporal ensembling）对重叠动作预测进行平滑。

## 主要结论与发现

1. **世界-动作联合建模有效**：单一扩散Transformer可以同时进行动作生成与未来视觉预测，且未来的RGB patch预测在训练中提供有效监督，而不影响推理效率。
2. **无需大型VLM骨干也能实现强性能**：WorldDiT在399.084M总参数（135.107M可训练参数）下达到98.0%（Spatial）、97.0%（Object）、92.8%（Goal）、91.8%（Long），均值94.9%。
3. **位于Pareto前沿**：在论文的对比中，所有成功率更高的方法都使用更多参数，而所有参数相近或更少的方法成功率均更低。
4. **Long仍是最难套件**，与长序列多阶段任务的一致性预期相符。
5. **统一的flow-matching公式**使得动作和视觉目标共享一个框架，未来可支持分解为独立训练的专家模块（在异构硬件和算力受限平台上部署）。

## 优点

- **架构简洁且统一**：一个共享骨干同时建模动作和世界，避免了大型VLM的巨额开销，清楚地分离了“架构贡献”与“规模贡献”。
- **训练-推理不对称设计**：RGB预测仅存在于训练时，推理路径保持纯动作生成，不增加部署负担。
- **强基线价值**：提供了亚十亿参数的SOTA级基线，明确为未来扩展研究而设计。
- **对参数-性能权衡的清晰刻画**：通过Pareto前沿分析，以直观方式呈现WorldDiT在规模-性能图谱中的位置。
- **对评估局限性的诚实披露**：明确指出了checkpoint选择造成的偏差风险和其他方法不可复现的问题，增加了报告的可信度。

## 不足与局限

- **评估偏差风险**：包含300个episodes/套件的checkpoint选择数据，报告的94.9%不应视为无偏测试估计。
- **缺少消融实验**：未系统验证RGB预测目标的贡献程度、损失权重的敏感性、模型规模的影响等关键设计选择。
- **缺乏统计可靠性指标**：未报告多次运行的标准差，无法判断性能的稳定性。
- **仅测试单一配置**：只评估了一个模型规模（深度4、隐藏维度1024），未提供不同规模的扩展曲线。
- **对比公平性有限**：不同方法的分数来自各自论文，评估协议可能不完全一致。
- **仅限仿真环境**：所有结果基于LIBERO模拟器（headless EGL），未涉及真实机器人部署验证。
- **训练时长未报告**：无法评估该方法在算力消耗方面的实际成本。
