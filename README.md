# Daily Paper Reader

个人每日论文推荐与阅读器。  
基于 [ziwenhahaha/daily-paper-reader](https://github.com/ziwenhahaha/daily-paper-reader) fork。

## 能做什么

- 按订阅自动抓取、推荐 arXiv / 会议论文
- 侧边栏阅读、收藏、未读管理
- 论文页 AI 问答（可停止 / 编辑重问）
- GitHub Actions + Pages，无需自建服务器
